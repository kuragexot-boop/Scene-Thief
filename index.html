シーン・シーフ Scene Thief

情景が、
そっと奪われる。

How to Use

テーマ

景色は、見つめた瞬間にはもう、
通りすぎている。

光の流れも、星のめぐりも、
雷のひらめきも、時のうつろいも。

あなたの指は、その一瞬を、そっと盗む。
触れたところが岩になり、
星が灯り、炎が揺れ、針が時をたぐる。

盗んだ景色は、どこにも持ち帰れない。
ただ、指先と耳の奥に、
静かな余韻だけがのこる。

使い方

♺ 移ろう情景

下の「♺」から、四つの景色へ。
清流、天図、雷火、刻景。

▷清流

夜の川を、光が音もなく流れてゆく。
指先にふれると、流れは少しだけ道をかえる。

  • ふれる … 指先が岩になり、光は身をかわして流れます。放せば、もとの流れへ。
  • くるくるなぞる … 光が渦に巻き取られます。放すと解き放たれ、また流れ出します。
  • ひとしずく落とす … 水面に波紋が広がり、通りすぎた光の色がゆるやかにかわります。

▷天図

星空に浮かぶ、惑星の軌道図。
そこへ、あなたの星をひとつ灯してみる。

  • ふれて灯す … 軌道図に星が灯ります。星は図とともに回り、惑星のように太陽のまわりをめぐります。
  • 灯した星に、もう一度ふれる … 星は静かに消えます。
  • 指をすべらせる … 軌道図を、どの向きにも回せます。速く、同じ向きに重ねるほど、回転は速まります。
  • 指でとめる … 回転が止まります。すべらせるのをやめると、ゆっくり減速して止まります。

▷雷火

黒い闇に、白い雷と炎。
走るものと、灯るもの。

  • 指をすべらせる … 指の進む先へ、雷が走ります。速いほど、長く太い雷に。
  • ふれる … 炎が、ほとばしるように灯ります。
  • ふれつづける … 炎が勢いを増します。そのままでいると、まわりへ飛び火して燃え広がります。放すと、広がった炎は順に静まり、もとの炎も静かに、もとの大きさへ戻ります。
  • すばやく、ふた度ふれる … 近くの炎が、ふわりと消えます。

▷刻景

文字盤のない、白い時計。
針をめぐらせると、星座と幾何学の背景が、過去から未来へ時をわたる。

  • 針を時計回りになぞりつづける … 針が四分の三ほどめぐるたび、景色はひとつ先へ。星空から、春夏秋冬の星座をたどり、幾何学のかたちをした未来の星座へ。最後は、また星空に還ります。
  • 反時計回りになぞる … 同じ道を、過去へさかのぼります。
  • 放したあと … 針は、少し余韻で回ります。
