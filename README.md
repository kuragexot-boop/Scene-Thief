# シーン・シーフ (Scene Thief)

静かな光の流れ「清流」と、星空に浮かぶ惑星軌道図「天図」、そしてほとばしる「雷火」、時をめぐる「刻景」。`index.html` 1枚だけで動く、ビルド不要のWebアプリです。

> 通りすぎる景色を、
> 指先で、そっと盗む。

起動するとタイトル画面が開きます。

## タイトル画面

ロゴと上のコピーの下、画面の下側に3つのボタンが並びます。

- **▷Start** … プレイ画面へ進みます。初回だけ、吹き出しで操作を案内します（NEXT → NEXT → START）。右下の「?」でいつでも見直せます。プレイ画面の下の「♺」と「?」のあいだにある「↩」でタイトルに戻れます（Start でその画面から再開）。
- **▷How to Use** … アプリのテーマを詩的に綴ったセクションと、詩的な言葉で綴った使い方のセクションが並ぶ画面です（細い画面では縦に並びます）。「◁ Back」でタイトルに戻ります。
- **▷Contact** … ご意見・感想・相談・不具合の報告の宛先（ot.shohji@gmail.com）を表示します。「◁ Back」でタイトルに戻ります。

## ♺ で画面を選ぶ

画面下の中央にある「♺」を押すと、「▷清流」「▷天図」「▷雷火」「▷刻景」の選択肢が表示されます。見たい画面をタップして切り替えます（いまの画面は明るく表示されます）。メニューの外をタッチすると閉じます。

## ▷清流

夜の川を、光が音もなく流れてゆく。指先にふれると、流れは少しだけ道をかえる。

- **ふれる** … 指先が岩になり、光は身をかわして流れます。放せば、もとの流れへ。
- **くるくるなぞる** … 光が渦に巻き取られます。放すと解き放たれ、また流れ出します。
- **タップ** … 水面に波紋が広がり、通りすぎた光の色がゆるやかにかわります。

## ▷天図

星空に浮かぶ、惑星の軌道図。そこへ、あなたの星をひとつ灯してみる。

- **タップ** … 軌道図に星が灯ります。星は図とともに回り、惑星のように太陽のまわりをめぐります。
- **灯した星をもう一度タップ** … 星は静かに消えます。
- **スワイプ** … 軌道図を、どの向きにも回せます。速く、同じ向きに重ねるほど、回転は速まります。
- **ふれる** … 回転が止まります。スワイプをやめると、ゆっくり減速して止まります。

## ▷雷火

黒い闇に、白い雷と炎。走るものと、灯るもの。

- **スワイプ** … 指の進む先へ、雷が走ります。速いほど、長く太い雷に。
- **タッチ** … 炎が灯ります。
- **長押し** … 炎が勢いを増し、打音がゆっくり溜めをつくります。しばらく押して放すと、ひと呼吸おいて締めの一打。炎は静かに、もとの大きさへ戻ります。
- **ダブルタッチ** … 近くの炎が、ふわりと消えます。

> 作り手メモ：長押しの連打は、ゆったり打ちはじめて数秒かけて詰まり、人の手で打てる速さ（約9打/秒）に落ち着きます。放したあとは、締めの一打から少し遅れて、遠い余韻の一打がもう一つ響きます（短い長押しでは鳴りません）。

## ▷刻景

文字盤のない、白い時計。針をめぐらせると、背景の姿が時をわたる。

- **針を時計回りになぞりつづける** … 針が四分の三ほどめぐるたび、景色はひとつ先へ。星空から、いのちの歩みをたどり、人、そして神へ。最後は、また星空に還ります。
- **反時計回りになぞる** … 同じ道を、さかのぼります。
- **放したあと** … 針は、少し余韻で回ります。

> 作り手メモ：背景の白いシルエットは、三角形・多角形・円を組み合わせた幾何学模様で、破片が呼吸するように動きます。順番は 星空 → 微生物 → 魚 → 小動物 → 恐竜 → 隕石 → 猿 → 現代人 → 神 → 星空。画面上の名称表示は出しません。

## 音

音は、触れた瞬間に、その場で生まれます。どの音が重なっても濁らない音階です。ブラウザの Web Audio API でその場で合成しているので、**音声ファイルは不要**です。

| 画面 | 音 |
| --- | --- |
| 清流 | 弦をはじくような、澄んだ音。高いところに触れるほど高く、なぞるほど、爪弾くように連なります。巻き取るときは、回す向きへ音が駆けます。タップは横の位置で音程が変わります |
| 天図 | 鍵を打つような、深くやわらかな響き。回した分だけ音が生まれ、減速とともに間遠くなります。内側の星ほど、高く鳴ります |
| 雷火 | 雷には、歪んだ力強い弦の響き。画面の上でなぞるほど高く。炎には、低く腹にひびく打音で、左右で音階が変わります。炎が消えるときは、低くやわらかい一打 |
| 刻景 | 時計回りは、澄んだ金属の粒のような音。反時計回りは、ぴんと張った弦をはじく音。針の向きで音階が変わり、中心から遠くをなぞるほど、高く澄みます |
| 画面の切り替え | 短い2音。移った先の画面の音色で鳴ります |

- 最初にふれるまで、音は眠っています（ブラウザの仕様です）。iPhone はマナーモードだと鳴りません。
- 左下の「♪」で音のオン／オフ、となりのスライダーを左右になぞると音量を変えられます（設定は記憶されます）。離すと確認の一音が鳴ります。ミュート中にスライダーを動かすと音が戻ります。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成（例: `scene-thief`）
2. 下の「ファイル構成」のファイルをすべてリポジトリのルートに置いて push
   ```sh
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/scene-thief.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment** の Source を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
5. 1〜2分後、`https://<ユーザー名>.github.io/scene-thief/` で動きます

スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `logo.png` | タイトル画面のロゴ（透過PNG） |
| `manifest.webmanifest` | ホーム画面に追加／インストール時の名前・アイコン設定 |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | インストール用アイコン |
| `apple-touch-icon.png` | iPhone のホーム画面アイコン |
| `favicon.png` | ブラウザのタブ用アイコン |
| `ogp.png` | X などSNSに貼ったときに表示される画像（黒背景・1200×630） |

### SNS に貼ったときの表示（OGP）

`index.html` の `<head>` にある `og:url` / `og:image` / `twitter:image` の `<ユーザー名>` を、自分のGitHubユーザー名に置き換えてください（SNSは相対パスの画像を読めないため、公開URLの絶対パスが必要です）。反映後、X が古い表示を覚えていることがあるので、変わらないときは時間をおいてから貼り直してください。

## 調整したいとき

`index.html` 上部のスクリプト内の定数で雰囲気を変えられます。

| 定数 | 意味 |
| --- | --- |
| `U0` | 川の流速 |
| `SW` | 渦の強さ |
| `TRAIL_N` / `STEP` | 光の線の長さ |
| `STATIC_ROCKS` | `true` で最初から岩が置かれる |
| `ROT` | 軌道図の回しやすさ（1pxあたりの回転角） |
| `MAX_SPIN` | 軌道図の回転速度の上限 |
| `MAX_LIT` | 灯せる星の数の上限 |

初回ガイドをもう一度出したいときは、ブラウザの localStorage から `seiryu.guide.v1` を消してください（保存キーは旧名称のまま引き継いでいるため、音量などの設定も以前のまま残ります）。
